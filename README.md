# 루틴 퀘스트

픽셀 RPG 스타일 루틴·운동 기록 앱의 Android 패키지 프로젝트입니다.

## Android APK 만들기
1. GitHub 저장소의 **Actions** 탭으로 이동합니다.
2. **Build Routine Quest Android APK** 워크플로를 선택합니다.
3. **Run workflow**를 누릅니다.
4. 완료된 실행의 Artifacts에서 `routine-quest-android-apk`를 다운로드하고 ZIP 안의 APK를 설치합니다.

앱 이름: 루틴 퀘스트  
Android application ID: `com.routinequest.app`

사용자 기록은 앱 내부 브라우저 저장소에 보관됩니다. 기기 변경 전 앱 설정에서 JSON 백업을 내려받으세요.
